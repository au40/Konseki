Always-on inbox

Optional. Point your devices at a box that's always on (a Pi, or any machine that stays up) and they can sync while this computer is asleep. Konseki collects whatever queued up there each time it runs. Leave blank to keep everything direct.

seconds

When an inbox is set, Konseki also sends it a dated copy of your database once a day, so your backups aren't all on this one drive. The inbox keeps them but will never hand one back over the network — to restore, copy the file off that machine directly.

Advanced

For power users. Defaults are fine for most setups.

How long GSM must be idle before the tracker pulls new stats. Increase this if GSM is resource-heavy while you're playing.

seconds

Off by default. If GSM was idle this long before a new write, pull immediately on the next write — catches the previous session's tail reading time that flushed after the app closed. Usually unnecessary: the normal settle pull already handles it. Set a value (e.g. 300) to enable.

seconds (0 = off)

GSM's /api/today-stats reports each sitting with a start and end time, and its real measured duration. The normal pull has neither — it works time out by dividing characters by speed, which loses real minutes when that speed figure runs high.

Shadow records and compares only; nothing you see changes. Use measured time additionally stores GSM's real duration — but only for a day it can prove it saw in full, by matching character counts. Any day it can't, it silently leaves alone, so the worst case is no improvement rather than a wrong number.
