Bring your existing immersion data into the tracker. Each section is independent — use whichever ones apply to you.

CSV columns: Activity, Language, Activity Type, Time (minutes), Date

2Import history from GameSentenceMiner

Reads GSM's local database directly to pull authoritative per-day chars and reading time for every game you've played. Per game: Track includes the game in the import; Count as time sets whether new rows count toward your time stats. Existing rows in your tracker keep whatever state they already have — the import never silently changes that.

3Import history from ッツ Reader

ッツ Reader can export all of your stats as a zip file. To import:

  1. Open ッツ Reader and go to the Statistics page.
  2. Click the option to download all stats as a zip.
  3. Drag the zip onto the ⬇ Drag ttsu log zip here button in the sidebar.

Default: off — only character counts are added to your stats. Today's sessions always count time fully, regardless of this setting.
